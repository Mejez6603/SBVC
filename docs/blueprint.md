# **App Name**: VerseView

## Core Features:

- Responsive Bible Text Display: Display Bible passages in a clean, responsive format optimized for various screen sizes.
- Desktop-Inspired Control Bar: Implement a control bar with buttons for key actions: Show Screen, Minimize, Theme Toggle, and Text Size Adjustment.
- External Presentation Mode: Open the selected passage in a separate, minimalist tab optimized for preaching/projection.
- Passage Recommendation: Suggest relevant Bible passages based on user's topical interests using a generative AI tool.

## Style Guidelines:

- Background color: Dark charcoal gray (#333333) to provide a distraction-free, dark-themed reading environment.
- Primary color: Soft gold (#D4A373) for text to ensure readability against the dark background.
- Accent color: Light beige (#F5EBDD) for interactive elements to highlight key functionalities.
- Body and headline font: 'Literata', a serif font, chosen for comfortable reading and a classic feel.
- Use minimalist, custom icons for the control bar buttons (Show Screen, Minimize, Theme Toggle, Text Size) to maintain a clean interface.
- Center the Bible text within a preview panel, allowing it to expand and resize smoothly on all screen sizes.
- Implement smooth transitions and subtle animations when toggling themes, adjusting text sizes, or opening the presentation mode.
